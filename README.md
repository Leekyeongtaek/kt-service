# Kt-Service

## 1. 프로젝트의 목적
* 기존 모놀리식 개발 방식을 벗어나 MSA 구조의 개발 환경 경험
* 깃 컨벤션을 준수하고, 커밋 이력 추적이 가능한 단위별로 커밋 메시지 작성하기
* 단위 테스트, 통합 테스트 작성 구현
* 로컬 환경에서 CI/CD 파이프라인 구현
* 강의나 책을 통해 학습한 내용은 요구사항 정의 -> 구현 단계를 통한 실전 학습

## 2. 기술 스택
* 백엔드: Java 17, Spring Boot 3.5, Spring Data JPA
* 데이터베이스: MySQL, Redis
* 분산 메시징: Kafka
* 아키텍처: MSA (Spring Cloud Gateway, Eureka)
* 테스트: JUnit5

## 3. 시스템 아키텍처
Draw.io 그림 첨부 (마지막)

## 4. 주요 기능

### 종목

#### 목록 조회

- 종목 정보 제공
  - 표준코드
  - 단축코드
  - 한글 종목명
  - 한글 종목약명
  - 영문 종목명
  - 상장일
  - 시장구분
  - 증권구분
  - 소속부
  - 주식종류
  - 액면가
  - 상장주식수
- 검색 기능 (단축코드, 한글 종목명, 한글 종목약명, 영문 종목명)
- 정렬 기능 (단축코드, 한글 종목약명, 상장일, 상장주식수)
- 필터 기능 (시장구분, 증권구분, 소속부, 주식종류)

##### 참고사항
- 검색 방식: 부분 일치(Contains)를 사용한다
- 필터 방식: 다중 조건으로 여러 개를 동시에 적용할 수 있고 AND 조건으로 동작한다

#### 인기 종목 Top10 목록 조회
- 현재 스코어가 가장 높은 상위 10개 종목의 목록을 조회
- 인기 종목 정보
  - 순위
  - 종목 ID
  - 한글 종목명
  - 단축코드
  - 시장구분 한글명

##### 구현 상세
- 레디스 ZSet 자료구조 사용

##### 테스트 상세
- [단위] 레디스에서 조회한 ID 순서가 인기 종목 목록에 적용 되어야 한다.
- [단위] 레디스에 인기 종목 데이터가 존재하지 않으면, 빈 목록을 반환해야 한다. 

#### 한정 종목 재고 설정
- 특정 종목에 대해 한정 종목을 설정하는 기능
- 파라미터 정보
  - 종목 ID
  - 재고 수량

##### 구현 상세
- 레디스 String 자료구조 사용
- 유효 기간 (레디스 TTL 1일)
